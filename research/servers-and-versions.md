# Servers & Versions
EverQuest has run on many servers since it launched on March 16, 1999. Most of the original servers have since been merged together, and since 2015 a steady stream of time-locked progression servers has replayed the game's history from the beginning. This page covers what is running today, how the special server types work, and what happened to the servers that are gone.

>Server information on this page is current as of October 2026.
{.is-info}

## Server Types
* **Standard (Live) servers** have every released expansion available and follow the normal rules of the game.
* **Progression servers**, also called time-locked progression (TLP) servers, start with older content and unlock expansions over time. They require an All Access membership.[^2]
* **Test** is where upcoming patches are tried out before they reach the other servers.
* **Beta** servers only open while a new expansion is in beta testing.

## Progression Servers
Progression servers open with only the early game available and unlock later expansions on a schedule, letting players experience EverQuest the way it unfolded. Each one has its own ruleset. Common variations include:

* **True box:** only one game client per computer.
* **Random loot:** rare and raid drops are randomized among NPCs of a similar level.
* **Free trade:** items that are normally no-trade can be traded.
* **Unlock pace:** most servers unlock a new expansion every 8 to 12 weeks.

## Test Server
Test receives patches before the other servers, so players can try upcoming changes and report problems. It does not require a subscription.[^3]

### Getting to Test
1. Make a copy of your EverQuest folder (by default in `C:\Users\Public\Daybreak Game Company\Installed Games\EverQuest`) and rename the copy, for example to `TestEverQuest`.
2. Run `LaunchPad.exe` from the copied folder and log in.
3. Click **Advanced Tools**, then **Select Game Version**, choose **Test**, and click **Apply**.
4. Let LaunchPad download the Test files, then click **Play**. Test will appear on the server list.

Keeping a separate folder for Test means you never have to repatch your main installation when you switch back.[^4]

### Copying a Character to Test
Type `/testcopy` while logged in on a Live server to copy that character to Test. There is an 8-hour cooldown per character.[^4]

* **Save first:** if you have just traded items or platinum to the character, zone or camp before copying, so the server has saved the change.
* **Overwrites:** a Test character with the same name will be replaced without warning, so be careful if you have been playing an earlier copy.
* **Copied items:** items brought over this way are flagged as copied.

On Test, `/testbuffme` raises a new character to level 25 with gear suited to its race and class once you have left the starting area.[^4]

## Other Versions of EverQuest

### EverQuest Macintosh Edition
EverQuest for the Macintosh launched in 2003 with its own server, Al'Kabor, for Mac players only. The server was effectively frozen at the Planes of Power expansion, keeping the rules and interface of that era long after the main game moved on. Sony announced its closure in 2012, reversed the decision after player feedback, and then shut it down for good on November 18, 2013.[^5] [The Al'Kabor Project](https://www.takproject.net/) now recreates it as an emulated server.

### Project 1999
[Project 1999](https://www.project1999.com/) is a free, fan-run emulated server that recreates EverQuest as it was in the classic era, as faithfully as possible. Its Blue server covers the Classic, Kunark and Velious eras, and its newer Green server aims at the same classic experience.[^6]

### EQEmulator
[EQEmulator](https://www.eqemulator.org/) is the open-source server software that most fan-run EverQuest servers, including the ones documented on this wiki, are built on.
